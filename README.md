# Sniffer CSV Layer Loader for QGIS

A QGIS Python plugin designed to easily import and process GPS CSV data exported from **Sniffer4DMapper** sensors. 

This tool automatically reads the CSV file, skips header metadata, extracts geographic coordinates (`Longitude` and `Latitude`), and creates an independent memory point vector layer (`EPSG:4326`) for each environmental parameter found in the dataset. Furthermore, each layer is automatically styled with a **Graduated symbology** (using a reversed *Spectral* color ramp) based on its measured values.

---

## Features

- **Automatic CSV Parsing**: Intelligently skips the initial metadata rows generated by Sniffer4DMapper and detects the correct header row.
- **Multi-Layer Generation**: Creates separate vector point layers for all major environmental metrics simultaneously:
  - Temperature (°C)
  - Humidity (%)
  - Pressure (Pa)
  - PM1.0, PM2.5, PM10 ($\mu g/m^3$)
  - CxHy / Flammable Gases (%)
  - CO2 ($mg/m^3$)
- **Automatic Graduated Symbology**: Immediately visualizes data using a 5-class Equal Interval classification paired with an inverted *Spectral* palette (from green/blue for low values to red for high values).
- **Metadata Preserved**: Retains timestamps and unique point identifiers for tracking and temporal analysis.

## Installation

### Method 1: Install from ZIP (Recommended)
1. Download the latest release `.zip` file from the repository (or compress your plugin folder containing `metadata.txt`, `__init__.py`, and `sniffer_plugin.py`).
2. Open **QGIS**.
3. Go to **Plugins** > **Manage and Install Plugins...**.
4. Select the **Install from ZIP** tab on the left.
5. Browse and select the downloaded `.zip` package and click **Install Plugin**.

### Method 2: Manual Installation
1. Locate your QGIS active profile plugins directory:
   - **Windows**: `C:\Users\<Your-Username>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
   - **Linux**: `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
   - **macOS**: `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/`
2. Create a folder named `sniffer_csv_loader` and place the plugin files (`metadata.txt`, `__init__.py`, `sniffer_plugin.py`) inside.
3. Restart QGIS and enable **Sniffer CSV Layer Loader** under the Plugin Manager.

---

## Usage

1. Once enabled, a new toolbar icon and a menu entry (**Vector** > **Sniffer CSV Loader**) will appear.
2. Click the plugin button to open the file selector.
3. Choose your exported Sniffer4DMapper CSV file (e.g., `20240509.CSV`).
4. The plugin will parse the file and automatically load all available environmental layers into your QGIS map canvas, fully styled and ready for analysis.
